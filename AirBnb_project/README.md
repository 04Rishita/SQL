# 🏠 Airbnb Data Analysis Using SQL

## 📌 Project Overview

This project focuses on analyzing **Airbnb listing and booking data using SQL**. The goal is to explore pricing, room types, neighbourhoods, hosts, reviews, availability, and minimum-night requirements and generate useful business insights.

The project contains **50 SQL queries**, ranging from basic data exploration to advanced SQL concepts such as **Joins, Aggregations, Subqueries, GROUP BY, HAVING, ORDER BY, and Self Joins**.

## 🎯 Objectives

* Analyze Airbnb listings, hosts, and locations.
* Compare prices across neighbourhoods and room types.
* Analyze reviews and listing availability.
* Identify high-priced and highly reviewed listings.
* Analyze host-level listing activity.
* Practice SQL for real-world data analysis.

## 📂 Dataset

The project uses two datasets:

* **`listings.csv`** – Listing, host, room type, and neighbourhood information.
* **`booking_details.csv`** – Price, reviews, minimum nights, and availability information.

The datasets are connected using the **listing ID**.

## 🛠️ SQL Concepts Used

* SELECT & DISTINCT
* WHERE, IN, BETWEEN, LIKE
* COUNT, SUM, AVG, MIN, MAX
* GROUP BY & HAVING
* ORDER BY & LIMIT
* INNER JOIN
* Subqueries
* Self JOIN
* Aggregate functions

## 🔍 Analysis Performed

### 💰 Pricing Analysis

Analyzed minimum, maximum, and average prices across different room types and neighbourhood groups.

### 🏙️ Neighbourhood Analysis

Compared listings, prices, reviews, and minimum-night requirements across different locations.

### 🛏️ Room Type Analysis

Compared room types based on price, reviews, and minimum-night requirements.

### ⭐ Review Analysis

Identified highly reviewed listings and neighbourhood groups with high review activity.

### 👥 Host Analysis

Analyzed hosts with multiple listings and compared their listing prices.

### 📅 Availability Analysis

Identified listings with high yearly availability and analyzed availability patterns.

### 🌙 Minimum Nights

Analyzed short-stay and long-stay listings based on minimum-night requirements.

## 📊 Project Output & Insights

The SQL analysis provides insights into:

* Pricing differences across locations and room types.
* Most and least expensive listings.
* Highly reviewed listings and areas.
* Hosts managing multiple properties.
* Listings with high availability.
* Differences in minimum-stay requirements.
* Relationship between location, price, reviews, and listing characteristics.
