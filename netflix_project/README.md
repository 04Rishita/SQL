# 🎬 Netflix Content Catalog & Release Trends Analytics

An Exploratory Data Analysis (EDA) project on Netflix's global content library. This analysis examines content type distribution (*Movies* vs. *TV Shows*), production country volume, rating distributions, and release year trends using analytical database queries.

---

## 📌 Project Overview
This project explores Netflix's content offerings using relational database techniques. It involves:

- Movie vs. TV Show ratio evaluation
- Country-wise content production tracking (*United States*, *India*, *United Kingdom*, etc.)
- Release year distribution and historical content addition velocity
- Sequential year-over-year release tracking

---

## 🎯 Objectives
- Analyze the proportion of Movies versus TV Shows in the catalog
- Identify top content-producing countries
- Evaluate historical content release year distributions (Earliest, Latest, Average release year)
- Track consecutive release trends over time
- Generate strategic content acquisition insights for streaming platforms

---

## 📁 Dataset & Files Included

### `netflix_titles.csv`
- **Content Metadata**: Show ID, Type (*Movie* / *TV Show*), Title, Director, Cast
- **Release Details**: Country of Origin, Date Added, Release Year, Rating, Duration, Listed In (Genres)

---

## 🛠️ Tools & Technologies
- **Data Engine**: Relational Database System (MySQL)
- **Analysis Environment**: Database Workbench

---

## 🔍 Key Analysis Topics Covered

### 1. 🍿 Content Type Breakdown
- Comparing the proportion of feature-length Movies versus multi-season TV Shows.

### 2. 🌍 Geographic Production Analysis
- Filtering catalog volume by origin country (*United States*, *India*, *Australia*, etc.).

### 3. 📅 Historical Release Timeline
- Summarizing earliest release years, newest releases, and catalog age metrics.

### 4. 🔄 Sequential Release Tracking
- Tracking back-to-back release year metrics across distinct catalog titles.

| :--- | :--- |

| **Top Content Producer** | The **United States** leads in total production volume, followed by **India** |
| **Peak Content Expansion** | Massive catalog growth registered for titles released after 2015 |

---

## 📌 Key Insights
- **Movie-Centric Catalog**: Feature films make up the vast majority of titles available on the platform.
- **Regional Content Hubs**: The US and India represent the largest content sourcing markets for Movies and Shows.
- **Modern Streaming Focus**: The platform prioritizes recent titles, with average catalog release dates heavily skewed toward post-2015 content.
