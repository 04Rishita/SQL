# 🚍 Public Transportation Management System

## 📌 Overview

This SQL project analyzes a public transportation system by managing data related to routes, vehicles, commuters, trips, stations, and maintenance to generate useful insights.

---

## 🎯 Objective

To improve transportation efficiency by analyzing route performance, vehicle usage, maintenance costs, and commuter behavior.

---

## 🗂️ Dataset

* Routes
* Vehicles
* Commuters
* Trips
* Stations
* Maintenance
* Route Assignment

---

## ⚙️ Features

* SQL queries using JOIN, GROUP BY, HAVING
* Subqueries and window functions (RANK)
* Views and indexing
* Data analysis and optimization

---

## 📊 Key Insights

* Identified busiest routes
* Analyzed revenue and trip patterns
* Found cost-efficient vehicle types
* Evaluated maintenance costs
* Detected unused vehicles

---

## 🛠️ Tools Used

* SQL (MySQL)

---

## 💡 Conclusion

This project helps in understanding and optimizing transportation systems using data-driven insights.
